Workflows de Automação — Visibill

Documentação simples das automações em n8n que integram o app financeiro ao WhatsApp. Base de dados em PocketBase, IA via Groq (Llama 3.3) e envio de mensagens pela Evolution API.

n8n WhatsApp / Evolution API PocketBase Groq · Llama 3.3 Whisper (áudio)

🧠 Arquitetura atual — n8n como cérebro Lumers Gestão

Nesta versão, o n8n orquestra o assistente (IA + leitura de documentos + regras) e o app Lumers é o provedor de dados e ações via a ponte api/n8n.js. O WhatsApp (Evolution) e o Chatwoot são apenas canais. Os pontos de conexão ficam no painel do sistema e o n8n os lê em tempo de execução — nada de credencial fixa no fluxo.

WhatsApp / Chatwoot→ Webhook → n8n→ n8n: IA + regras + documentos→ api/n8n.js (dados/ações)→ Responde no canal

Ponte api/n8n.js — POST com header x-n8n-secret. Operações:

opO que faz
getConnectionsDevolve os pontos de conexão do painel (Chatwoot, Evolution padrão, chaves/modelos de IA) para o n8n se auto-configurar
getRulesRegras gerais (texto do admin) + documentos ativos da base de conhecimento (para prompt/RAG)
userByPhoneEncontra o usuário pelo número de WhatsApp
getUserContextContexto financeiro: contas, categorias, contas a pagar pendentes, metas e totais do mês
getMediaBase64 / getAudioBase64Baixa mídia (imagem/PDF/áudio) em base64 para OCR/transcrição/leitura
addTransaction / addInstallmentRegistra lançamento avulso / parcelamento
createCategory / createAccountCria categoria de receita/despesa / conta-carteira
markBillPaidDá baixa numa conta a pagar (status pago + data)
sendMessage / sendChatwootResponde no WhatsApp (Evolution) / no Chatwoot

Configuração no painel (Admin → Sistema): seção Integração n8n (URL do webhook + secret), seção Chatwoot (URL, token, account/inbox) e seção Regras & Base de conhecimento.

🤖 Automação Visibill v2 Webhook (tempo real)

O cérebro do sistema. Recebe cada mensagem que o usuário manda no WhatsApp, entende a intenção com IA e responde — registrando gastos, respondendo dúvidas ou conversando.

Mensagem no WhatsApp→ Filtra (ignora grupos/próprias)→ É áudio? Transcreve (Whisper)→ IA interpreta a intenção→ Executa a ação certa→ Responde no WhatsApp

O que o usuário pode fazer só mandando mensagem (ou áudio):

  • Registrar gasto/receita — "gastei 50 no mercado", "recebi 2000 de salário". A IA classifica automaticamente em receita, despesa futura ou gasto já pago.
  • Parcelar compras — "comprei uma TV em 10x de 300". Cria o parcelamento e já mostra a 1ª parcela.
  • Marcar conta como paga — "paguei a conta de luz", "quitei o aluguel".
  • Cancelar o último lançamento — "cancela o último", "errei no último".
  • Criar meta de economia — "cria meta de 5000 para viagem".
  • Criar recorrência mensal — "adiciona academia 150 todo dia 5".
  • Consultar finanças — saldo do mês, contas a vencer, status das metas, maiores gastos, comparativo com o mês anterior, gasto por categoria, previsão de quando atinge a meta.
  • Conversar livremente (Chat Agent) — tira dúvidas gerais; a IA consegue puxar saldo/contas/metas do usuário e até buscar informação na web (Tavily) quando precisa.

Como funciona por dentro:

  • Se a mensagem for áudio, o áudio é baixado e transcrito por Whisper antes de continuar.
  • A IA (Llama 3.3 via Groq) devolve um JSON classificando a mensagem em um dos tipos: income, expense, general, installment, payment, ações (cancel_last, create_goal, create_recurring), consulta ou chat.
  • Conforme o tipo, um "Handler" específico executa a operação no PocketBase e monta a resposta.
  • O histórico das conversas de chat e consultas é salvo para dar contexto às próximas mensagens.

🎉 Parabéns de Meta Visibill Diário · 9h (Brasília)

Acompanha as metas de economia de cada usuário e comemora quando ele cruza marcos importantes — reforço positivo para manter o hábito.

Cron 9h→ Busca metas de cada usuário→ Calcula % atingido→ Parabeniza (50% / 100%)
  • Envia mensagem ao atingir 50% da meta (com barra de progresso e quanto falta).
  • Envia mensagem de conquista ao chegar a 100%.
  • Usa uma "memória" (staticData) para nunca repetir o mesmo parabéns.
🏆 *Incrível, Maria!* Você concluiu sua meta *Viagem*! 🎊 ██████████ 100% 💰 R$ 5.000,00 — objetivo atingido!

☀️ Resumo Semanal Visibill Segunda · 8h (Brasília)

Toda segunda de manhã envia uma retrospectiva da semana anterior + a agenda de contas da semana que começa.

Toda segunda 8h→ Autentica + busca usuários→ Soma semana passada→ Lista contas da semana→ Envia resumo
  • Receitas e gastos pagos nos últimos 7 dias, com saldo da semana.
  • Lista de contas pendentes que vencem nos próximos 7 dias, ordenadas por data.
  • Total a pagar na semana + dica de como registrar gastos.

🔐 Atenção antes de portar para o Lumers Flow

Os arquivos .json desses workflows contêm credenciais em texto puro (senha do PocketBase, chaves da Evolution API, Groq e Tavily). Ao migrar para o novo projeto:

  • Troque todas as chaves/senhas e mova para credenciais do n8n ou variáveis de ambiente — nunca deixe fixas no código.
  • Ajuste as URLs (PocketBase, Evolution) e a instância do WhatsApp para o ambiente do Lumers Flow.
  • Reveja o schema das coleções (users, transactions, goals) para bater com o banco do Lumers Flow.
  • Reconfigure o webhook da Evolution API para apontar para o novo endpoint do n8n.
